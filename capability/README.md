# capability/

What **September - Comparision** can and cannot do.

## What belongs here

- Capability definitions: September LY/TY comparison, YoY calculation,
  A/B/C/D segmentation, Account and Segment filtering, the output data contract
- Explicit boundaries and refusals
- Stated limits, including rules that are not yet numerically defined

## What does not belong here

- Implementation and design detail — that belongs in `documentation/`
- Proof a capability works — that belongs in `evidence/`
- Validation checks — those belong in `validation/`
- Capabilities the project does not actually have

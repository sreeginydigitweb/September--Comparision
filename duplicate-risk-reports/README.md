# duplicate-risk-reports/

Where this project risks rebuilding something that already exists.

## What belongs here

- Reusable assets found elsewhere and the decision taken on each
- Naming collisions and how they were resolved
- Anything deliberately excluded from scope, with the reason
- Re-checks when a new component is proposed

## What does not belong here

- General project documentation — that belongs in `documentation/`
- Source mappings — those belong in `data-maps/`
- Silent duplication. If something was copied rather than referenced, it is recorded here

# handover/

What another person or session needs to pick this project up without re-running Discovery.

## What belongs here

- Current stage, what is done, what is next
- Open questions awaiting a business answer
- Access notes: which MCP/database connection to use and its read-only posture
- Known traps that would otherwise be rediscovered the hard way

## What does not belong here

- Full specifications — link to `documentation/` instead of restating it
- Credentials, passwords or connection secrets of any kind
- Completion sign-off — that belongs in `closure/`

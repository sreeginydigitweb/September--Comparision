# evidence/

Proof that something in **September - Comparision** is actually true.

## What belongs here

- Query result snapshots taken from `ledsone` (read-only), with the date taken
- Row counts, coverage checks and date-range checks backing a claim
- Before/after comparisons used to justify a mapping decision
- Screenshots or exports that evidence a source figure

## What does not belong here

- Rules, definitions or design decisions — those belong in `documentation/`
- Source-to-field mappings — those belong in `data-maps/`
- Reusable SQL — that belongs in `sql/` or `query-packs/`
- Anything unverified. If it is an assumption, label it in `documentation/`, not here

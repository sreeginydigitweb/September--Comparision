# documentation/

The authoritative written record of **what this project is and what has been decided**.

## What belongs here

- The project baseline: scope, LY/TY definition, expected output table, filters
- Segment rules as supplied, and which of them are still undefined
- Decisions taken, with the reason and the date
- Verified business rules imported from the shared knowledge base, with their source path

## What does not belong here

- Proof a figure is correct — that belongs in `evidence/`
- Field-to-column mappings — those belong in `data-maps/`
- Capability boundaries — those belong in `capability/`
- Invented answers to open questions. Unresolved items are recorded as PENDING ANALYSIS, not guessed
